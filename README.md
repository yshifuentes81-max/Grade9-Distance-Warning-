The ultrasonic sensor detects objects by sending out sound waves that bounce back when they hit an object. It measures the distance and
sends the information to the Arduino Uno. The Arduino checks how far the object is and decides whether to turn on the warning LED.
If the object is less than 20 cm away,the LED turns ON to warn the user that something is too close. If the object is 20 cm or farther,
the LED stays OFF.
